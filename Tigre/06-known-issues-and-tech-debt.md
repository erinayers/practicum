## Design debts (after Phase 7)

- ~~MainWindow is one tall form~~ → screen stack done (Tigre/03). Screens emit signals; MainWindow
  owns API calls. Keep it that way.
- `ApiClient` is synchronous httpx + QThread per call; the running view polls every 1–5 s, so a
  shared `httpx.Client` (connection reuse) would be a cheap win.
- Mixed line endings per file (CRLF: all of `desktop/`, `ports.py`, `test_ports.py`,
  `test_service.py`, `HANDOFF.md`, most story markdown; LF: the rest). No `.gitattributes`.
  Preserve each file's existing ending when editing.
- `DesignerView` still holds its draft as three lists of dicts; an "edit existing lab" story
  (S-7) should introduce a small draft dataclass and a `load(lab)`.
- The gate, import dialog and running view each poll `/status` with their own QTimer; a shared
  `StatusPoller(QObject)` would remove the triplication if a fourth consumer appears.
- ~~Emoji glyphs are used as icons~~ → the design icon set (`icons.py`, `assets/icons/`) since
  2026-10-25 (incl. the painted topology cards and the designer's machine rows after the
  user's review; refresh/stop derived by the slicing tool in the second round); remaining
  text glyphs: × ▾ ▸ (no artwork supplied, not status cues).
- Two probes of `docker info` exist on purpose: the desktop's `docker_status.py` (status chip,
  Create-screen readiness — works even when the API is down) and the API's `GET /docker/engine`
  (gate, import, start re-check — the server stays authoritative). Same parse, kept in sync by
  hand; fold into one if a third consumer appears.
- `WINDOWS_INIT_SCRIPT` is PowerShell embedded in a Python f-string (braces doubled). It has been
  read carefully but not executed (no PowerShell in the sandbox); keep changes small and re-check
  the brace pairs (`tests/test_quickstart.py` asserts the contract, not the syntax).
