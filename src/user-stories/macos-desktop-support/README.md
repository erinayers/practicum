# Epic: macOS Desktop Support

## Epic Goal

Let Mac users install and use Practicum's existing desktop workflows to design, import, and run
Linux-container labs through Docker Desktop for Mac.

Windows-container labs are outside this epic and remain unavailable on macOS.
