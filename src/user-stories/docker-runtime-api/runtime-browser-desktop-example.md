# Browser Desktop Example Spec

## User Story

As a lab designer,  
I want an example browser desktop lab spec,  
so that I can understand how to create GUI/browser-accessible labs in Practicum.

## Why This Matters

The feature is easier to use when creators can copy a working example. A concrete Ubuntu web desktop spec shows how command behavior, port mappings, environment variables, and shared memory fit together.

## Functional Requirements

- The repository includes an example browser desktop spec.
- The example uses an image designed for browser access.
- The example maps browser-accessible ports.
- The example uses image default startup behavior.
- The example includes manual instructions.

## Acceptance Criteria

- `examples/ubuntu-webtop.json` exists.
- The example validates as an Practicum lab spec.
- The example defines browser-accessible ports.
- The example tells students what URL to open.
