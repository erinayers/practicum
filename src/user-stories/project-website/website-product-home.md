# Explain Practicum on the Project Website

As an instructor or student discovering Practicum, I want a clear overview of what it does so I can quickly decide whether it fits my networking-lab workflow.

## Acceptance criteria

- The home page explains in plain language that Practicum helps instructors author and distribute reproducible networking labs and helps students run them locally with Docker.
- The page presents the instructor and student workflows with clear next steps for each audience.
- The site explains the local-first model and the free open-source core accurately, including the need for Docker Desktop to run labs.
- Screenshots or a short product walkthrough show the current desktop app and are kept representative of released functionality.
- Paid or hosted roadmap concepts are clearly labeled as future plans and are not presented as available product capabilities.
- The page works on mobile and desktop, loads promptly, and has accessible headings, link text, and image descriptions.
