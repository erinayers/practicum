# Find and Download Practicum Releases

As a prospective user, I want a simple, trustworthy path to the current installer and source code so I can install Practicum or inspect and build it myself.

## Acceptance criteria

- A prominent download action leads to the latest published Windows release and identifies the current version and supported platform.
- The website links to the canonical release page rather than hosting duplicate installer binaries.
- Users can find source code, license, release notes, and prior releases from the download area.
- Installation prerequisites and the first-launch steps are shown before download, including the Docker Desktop requirement for running labs.
- If no release is published or the download is unavailable, the page says so and provides the source/build instructions instead of a dead link.
- Download links and version details can be updated without editing multiple pages.
