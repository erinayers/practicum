# Understand the Project and Contribute

As a prospective user, contributor, or institution evaluating Practicum, I want clear project, license, and roadmap information so I can judge its openness, health, and direction.

## Acceptance criteria

- The site links to the repository, license, contribution guide, issue tracker, and security-reporting instructions where available.
- The open-source/free core is stated consistently with the repository's open-core boundary, including that local lab authoring, import/export, and Linux Docker runtime remain available without a paid account.
- Hosted marketplace and institutional features are labeled as roadmap concepts unless and until they are released.
- The site provides a concise project status or release history with links to the canonical GitHub releases and changelog.
- Any project contact or support route shown on the site is real, maintained, and has a clear expected response level.
- The site does not collect personal information or use tracking by default; any future analytics or signup form is disclosed with its purpose and privacy information.
