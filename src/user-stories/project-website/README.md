# Project Website Stories

These stories cover a public website for explaining, distributing, and building trust in the
open-source Practicum application. The website should link to GitHub for canonical releases and
source instead of maintaining a second binary distribution channel. Keep any hosted or paid
roadmap concepts clearly separate from capabilities users can download today.

Stories:

- [Product home page](website-product-home.md)
- [Downloads and releases](website-downloads.md)
- [Getting started and help](website-getting-started.md)
- [Project transparency and contribution](website-project-transparency.md)
