# Get Started and Find Help

As a new Practicum user, I want a short getting-started path and links to reliable help so I can reach my first running lab without guessing.

## Acceptance criteria

- The site provides separate quick paths for students importing a lab and instructors creating or exporting one.
- The student path covers installing Practicum, installing/starting Docker Desktop, importing a sample or instructor-provided JSON lab, and starting it.
- The instructor path links to the lab format and explains how to create, validate, export, and share a lab.
- Troubleshooting links address common setup issues and point to maintained project documentation or issue discussions.
- Documentation clearly distinguishes prerequisites for running labs from requirements for authoring and validating lab files.
- The getting-started material is reviewed against the current release workflow and updated when installation steps change.
