# Instructor Progress Dashboard

## User Story

As an instructor,  
I want to see student progress across assigned labs,  
so that I can identify who needs help.

## Acceptance Criteria

- Instructor can view completion by class.
- Instructor can view progress by student.
- Dashboard shows lab start, stop, and checkpoint status where available.
- Student privacy settings and institutional policies are respected.

## Paywall Guidance

Hosted class-level analytics should be paid. Local individual progress remains open source.
