# Automated Lab Checkpoints

## User Story

As an instructor,  
I want labs to include automated checkpoints,  
so that students can verify their work and I can assess completion.

## Acceptance Criteria

- Lab specs can define checkpoint checks.
- Student can run checks locally.
- Results can be stored locally.
- Hosted classrooms can optionally sync results to instructors.

## Paywall Guidance

Local checkpoint execution could be open source if it is part of the spec/runtime. Hosted reporting, aggregated analytics, and advanced assessment packs can be paid.
