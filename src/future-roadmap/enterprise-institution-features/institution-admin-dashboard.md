# Institution Admin Dashboard

## User Story

As an institution admin,  
I want a dashboard for users, classes, labs, and policies,  
so that Practicum can be managed across an organization.

## Acceptance Criteria

- Admin can view active users.
- Admin can view classes and assigned labs.
- Admin can configure institution policies.
- Admin can review marketplace purchases or licenses.

## Paywall Guidance

Admin dashboards should be paid because they are hosted operational tooling.
