# Premium Support Plan

## User Story

As an institution,  
I want access to premium support,  
so that I can deploy Practicum confidently in a course or training program.

## Acceptance Criteria

- Institution can purchase support.
- Support plan defines response expectations.
- Support can include onboarding, troubleshooting, and deployment guidance.

## Paywall Guidance

Premium support is a clean monetization path that supports the open-source core without reducing free functionality.
