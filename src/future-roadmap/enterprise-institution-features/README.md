# Epic: Enterprise and Institution Features

## Epic Goal

Support schools, universities, bootcamps, and companies that need administrative controls, compliance, identity integrations, and support.

## Paywall Recommendation

Enterprise and institution features should be paid. They provide operational value without limiting individual open-source users.
