# Private Container Registry Policies

## User Story

As an institution admin,  
I want to configure approved container registries,  
so that labs use trusted images and comply with institutional policy.

## Acceptance Criteria

- Admin can define approved registries.
- App warns or blocks unapproved images according to policy.
- Policy can be applied to marketplace imports and local specs.
- Policy status is visible before a student starts a lab.

## Paywall Guidance

Basic image fields remain open source. Institution policy enforcement can be paid.
