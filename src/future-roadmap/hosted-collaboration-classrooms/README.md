# Epic: Hosted Collaboration and Classrooms

## Epic Goal

Provide hosted services for instructors who need to distribute labs, manage classes, and coordinate student work at scale.

## Paywall Recommendation

Classroom coordination is a strong paid tier because it requires hosted accounts, rosters, assignments, progress sync, and support.
