# Cloud Sync for Lab Progress

## User Story

As a student,  
I want my lab progress to sync across machines,  
so that I can continue work even if I switch devices.

## Acceptance Criteria

- Student progress can sync to a hosted account.
- Progress can be restored on another machine.
- Sync does not modify the instructor's original lab spec.
- Student can use local-only mode without cloud sync.

## Paywall Guidance

Local progress should remain open source. Cloud sync is a paid convenience feature because it requires hosted storage and account infrastructure.
