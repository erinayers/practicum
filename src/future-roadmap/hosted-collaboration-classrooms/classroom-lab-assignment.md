# Classroom Lab Assignment

## User Story

As an instructor,  
I want to assign labs to a class,  
so that students can access the correct lab files without manual file distribution.

## Acceptance Criteria

- Instructor can create a class.
- Instructor can assign a lab to the class.
- Students can see assigned labs.
- Students can open or import assigned labs into the local app.

## Paywall Guidance

This should be paid because it depends on hosted accounts, class state, and distribution workflows.
