# Epic: Marketplace Platform

## Epic Goal

Create a web platform where instructors and creators can share, discover, sell, and update Practicum spec files. Practicum can collect a platform percentage from paid sales while preserving open local import/export.

## Monetization Fit

This is one of the strongest paywall opportunities because it provides hosted value beyond the local open-source app.

## Suggested Revenue Model

- Free public listings: no fee or optional platform visibility rules
- Paid listings: Practicum takes a percentage of each sale
- Private listings: included in paid creator or institution plans
- Featured placement: optional paid promotion later, used carefully
