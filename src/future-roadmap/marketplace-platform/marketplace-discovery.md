# Marketplace Discovery

## User Story

As an instructor or learner,  
I want to search and filter marketplace labs,  
so that I can find labs that match my class, skill level, and technical requirements.

## Acceptance Criteria

- Users can search by title, topic, creator, and tags.
- Users can filter by free/paid, difficulty, runtime requirements, and rating.
- Listings show Docker image requirements and estimated resources.
- Listings show compatibility with Practicum versions.

## Paywall Guidance

Basic discovery should be free. Advanced promotion, institutional curation, or private catalogs can be paid.
