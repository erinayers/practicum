# Private Marketplace Listings

## User Story

As an institution or training company,  
I want private marketplace listings,  
so that I can distribute labs only to approved students or customers.

## Acceptance Criteria

- Creator can publish a private listing.
- Access can be limited to invited users, groups, or institutions.
- Private listings do not appear in public search.
- Authorized users can import the spec into Practicum.

## Paywall Guidance

Private listings are a strong paid feature because they require hosted access control and support institutional workflows.
