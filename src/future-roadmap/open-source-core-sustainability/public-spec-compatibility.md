# Maintain Public Spec Compatibility

## User Story

As a lab creator,  
I want Practicum specs to remain portable and documented,  
so that I can share labs without depending on a hosted marketplace.

## Recommendation

The lab spec should remain an open documented format. Marketplace publishing can add metadata, licensing, pricing, ratings, and version channels, but the underlying runnable lab should remain portable.

## Acceptance Criteria

- Spec schema is publicly documented.
- Local app can import specs from disk.
- Marketplace specs can be downloaded or exported when licensing allows.
- New schema versions include migration guidance.

## Paywall Guidance

Keep schema usage open source. Paywall marketplace hosting, sales tools, private distribution, and advanced validation services.
