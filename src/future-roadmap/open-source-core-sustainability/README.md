# Epic: Open Source Core Sustainability

## Epic Goal

Protect the long-term quality and usefulness of the open-source Practicum core while creating clear boundaries for paid features.

## Product Position

The open-source core should be a complete local lab platform. A student or instructor should be able to create, import, validate, and run labs without paying.

Paid offerings should make Practicum easier to scale across classrooms, teams, institutions, and commercial distribution.
