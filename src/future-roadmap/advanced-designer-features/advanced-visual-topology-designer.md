# Advanced Visual Topology Designer

## User Story

As a professional lab creator,  
I want an advanced visual topology designer,  
so that I can create complex labs faster and with fewer configuration mistakes.

## Acceptance Criteria

- Creator can drag nodes and networks onto a canvas.
- Creator can connect nodes visually.
- Canvas supports auto-layout.
- Canvas shows validation warnings inline.
- Canvas can export to the public lab spec format.

## Paywall Guidance

Basic form-based topology editing should remain open source. Advanced canvas productivity features can be paid, especially if they save significant authoring time.
