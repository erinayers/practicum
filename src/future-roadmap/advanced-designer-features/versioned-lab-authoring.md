# Versioned Lab Authoring

## User Story

As a lab creator,  
I want to manage multiple versions of a lab,  
so that I can improve content without disrupting students already using an older version.

## Acceptance Criteria

- Creator can create a new version from an existing lab.
- Marketplace can show version history.
- Students can see when an update is available.
- Breaking changes can be marked.

## Paywall Guidance

Simple version fields should remain open source. Hosted version history, release channels, and update distribution can be paid marketplace features.
