# Epic: Advanced Designer Features

## Epic Goal

Add premium productivity features for instructors and content creators while keeping basic lab creation open source.

## Open Source Baseline

Basic Designer Mode should remain open source:

- Create labs
- Edit metadata
- Add nodes, networks, and interfaces
- Author manuals
- Validate and export specs

## Paid Advanced Features

- Visual topology canvas with advanced layout tools
- Lab templates and reusable components
- Multi-version lab authoring
- AI-assisted manual drafting or topology generation
- Marketplace publishing workflow
- Advanced validation and linting
