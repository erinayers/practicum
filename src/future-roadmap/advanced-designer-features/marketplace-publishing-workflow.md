# Marketplace Publishing Workflow

## User Story

As a creator,  
I want to publish directly from Designer Mode to the marketplace,  
so that I can move from authoring to distribution without manual upload steps.

## Acceptance Criteria

- Creator can connect a marketplace account.
- Creator can validate the lab before publishing.
- Creator can set listing metadata, price, license, and visibility.
- Creator can publish updates to existing listings.

## Paywall Guidance

Direct marketplace publishing is paid-platform adjacent. Basic local export remains open source; hosted publishing workflow can be paid or require a marketplace account.
