# Reusable Lab Templates

## User Story

As an instructor,  
I want reusable lab templates,  
so that I can build new labs from known-good starting points.

## Acceptance Criteria

- Creator can save a lab as a template.
- Creator can create a new lab from a template.
- Templates can include topology, manual sections, and default resources.
- Templates can be private or published to the marketplace.

## Paywall Guidance

A small set of starter templates can be open source. Private template libraries, marketplace template packs, and team-shared templates can be paid.
